Building this site

September 11, 2026 · Week 2

First class assignment. Set up the repository, got it on GitHub Pages, and picked type and color.

What I changed

I kept the structure and changed everything in custom.css. The body font is Inter and the headings are Averia. I wanted to keep Inter because I thought it was simple, clean and effective for the body, but Averia with Serif addsmore contrast. I chose the background color because it is a clean neutral, and one of my favorites.

What broke

My stylesheet did nothing for about twenty minutes. I had the two <link> tags in the wrong order, so simple.css was loading second and overwriting all of my colors. Order matters.

The second thing: I put the @import for the fonts halfway down the file. It has to be the first line.
